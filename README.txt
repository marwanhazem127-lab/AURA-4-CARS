AURA FOR CARS — نسخة متجر تجريبية مطوّرة

الموجود: واجهة عربية، شعار وصورة السيارة، تصفح وبحث وتصنيف المنتجات، سلة مشتريات، نموذج إتمام شراء يجمع بيانات العميل وعنوان التوصيل، رقم طلب، وحفظ الطلبات في لوحة الإدارة مع تغيير الحالة. لا يتم تحويل العميل تلقائيًا إلى واتساب.

التشغيل: فك الضغط وافتح index.html في Chrome أو Edge. افتح admin.html لإدارة المنتجات والطلبات. كلمة مرور الإدارة التجريبية: Aura2026!

حدود مهمة: هذه نسخة Front-end محلية. المنتجات والطلبات محفوظة في LocalStorage على نفس المتصفح والجهاز فقط؛ لن تظهر طلبات الزبائن على جهازك إذا كان الموقع منشورًا على الإنترنت، ولا توجد قاعدة بيانات مشتركة أو بوابة دفع إلكتروني أو تحصيل عربون تلقائي. لا تستخدمها لاستقبال طلبات حقيقية من زوار الإنترنت قبل ربط Backend وقاعدة بيانات آمنة وتسجيل دخول خادمي.

العربون: النموذج يعرض عربونًا مطلوبًا بحد أقصى 300 جنيه من إجمالي الطلب، لكنه لا يحصّله إلكترونيًا. يجب ربط بوابة دفع مصرية عند تجهيز النسخة الإنتاجية.
